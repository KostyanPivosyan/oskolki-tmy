# ОСКОЛКИ ТЬМЫ

Локальный браузерный ARPG в духе Diablo II. Один мир, три класса, квестовая цепочка, босс с фазами, снаряжение с тирами, процедурные пиксельные спрайты и синтезированный звук — всё без единого внешнего ассета.

## Запуск

Откройте `index.html` в любом современном браузере — сборка и сервер не нужны. Сохранения хранятся в `localStorage` браузера (кнопка «Продолжить» на титульном экране).

## Управление

| Ввод | Действие |
|---|---|
| ЛКМ | Идти / атаковать цель |
| ПКМ | Второй навык |
| 1–4 | Навыки |
| WASD / стрелки | Движение |
| Q / E | Зелье здоровья / маны |
| F | Говорить, открыть сундук |
| C | Герой и снаряжение |
| Esc | Пауза |

В инвентаре: ЛКМ по предмету — надеть, ПКМ — продать, клик по надетому — снять. При наведении на выпавший предмет показывается сравнение характеристик с надетым в процентах.

## Классы

- **Варвар** — ближний бой: вихрь, рывок, боевой клич
- **Чародейка** — огонь и лёд: огненные снаряды, кольцо льда, телепорт
- **Следопыт** — лук и яды: веер стрел, кувырок, ядовитый залп

## Особенности

- Квестовая цепочка из трёх заданий и финальный босс «Владыка костей» с призывами и телеграфами ударов
- Три уровня сложности: Обычный / Кошмар / Ад
- Респаун монстров в духе Diablo: убитые не возвращаются в текущей сессии, мир обновляется при новом заходе
- Снаряжение трёх тиров, сумка на 12 предметов, торговец зельями
- Динамическое освещение: факелы, фонари, порталы и снаряды светят в темноте

## Структура проекта

```
index.html      — разметка, HUD и экраны
css/style.css   — стили интерфейса
js/utils.js     — константы, математика, холст
js/state.js     — общее состояние игры
js/data.js      — классы, навыки, монстры, NPC, квесты
js/audio.js     — синтез звука (Web Audio)
js/sprites.js   — процедурные спрайты
js/world.js     — генерация карты, декорации, коллизии
js/entities.js  — игрок, монстры, лут, снаряжение
js/combat.js    — навыки, ИИ, игровой цикл
js/render.js    — отрисовка, свет, миникарта
js/ui.js        — HUD, инвентарь, тултипы, диалоги, сохранения
js/main.js      — ввод, главный цикл, запуск
```
